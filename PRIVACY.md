# Privacy Policy

Effective August 13, 2026

Screen Timeout Tile does not collect, store, share, or sell personal data.

The app has no internet permission, accounts, advertising, analytics, or tracking. It stores no user content and disables Android backup and device-transfer backup.

Android requires the **Modify system settings** permission before the app can read or change `Settings.System.SCREEN_OFF_TIMEOUT`. Screen Timeout Tile uses that access only to read the current screen timeout and switch it between 30 seconds and 10 minutes. The app does not use the permission to change any other system setting.

You can revoke this access at any time from Android Settings. You can also remove the Quick Settings tile or uninstall the app at any time.

Questions can be opened as an issue in the project’s public GitHub repository.
